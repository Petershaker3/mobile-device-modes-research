# Path.GetFullPath("Z:\\no-access\\x.log") is a no-op on Windows - the drive is
# simply absent. On Linux "Z:\\no-access\\x.log" is a relative filename, so
# GetFullPath resolves it against the working directory and returns
# /home/runner/work/.../Z:\no-access\x.log instead.

# Asserts that deleting a directory fails while another handle holds a file
